# Runtime report collection retired

The report-only runtime availability collector and its daemon context adapter are retired with the runtime report screen/request path. No runtime file search, metadata collection or health probe replaces them.

Ordinary runtime selection, inherited environment handling, system Git behavior, voice checks and cached MCP behavior remain unchanged. Finite indicative guidance used by explicit `dot_review_status` is not part of this removal.

This is source-only retirement. It does not establish installed Windows behavior or authorize deleting runtime files, repairing dependencies, replacing environments or compiling the application. The owner compiles.
